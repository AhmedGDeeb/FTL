# FTL Syria – Kaggle Machine Learning Challenge

## 🚢 Challenge: Titanic – Machine Learning from Disaster
- **Kaggle Competition:** [https://www.kaggle.com/competitions/titanic](https://www.kaggle.com/competitions/titanic)

## 🎯 Objective
Build a machine-learning classification model to predict whether Titanic passengers survived, using passenger information such as age, sex, passenger class, and fare. 

The aim is to apply the machine-learning concepts learned in FTL Syria, practise model evaluation, and develop a complete ML workflow.

## 📋 Instructions and Requirements
- Work individually, unless otherwise agreed with the instructors.
- Create or use your Kaggle account with a recognisable username, preferably your full name or registered programme name.
- Explore the training data and identify relevant features.
- Prepare the data appropriately, including handling missing values and encoding categorical variables where necessary.
- Train and evaluate at least one classification model. You are encouraged to compare two or more models, such as Logistic Regression, Decision Trees, Random Forest, or Gradient Boosting.
- Use a validation set to evaluate your model before submitting predictions.
- Generate predictions for the provided test set and submit your CSV file directly to Kaggle.
- Complete the Microsoft Form below with your Kaggle username, public leaderboard accuracy, model used, and submission status.
  - **Submission form:** [https://forms.cloud.microsoft/e/zgP6eVudnV](https://forms.cloud.microsoft/e/zgP6eVudnV)

## 🏆 Performance Target
- **Target:** At least **75%** public leaderboard accuracy.
